# ERC-6551 — registry

Le Registry crée un compte à partir d’une implémentation, d’une chaîne, d’un token contract et d’un tokenId. Il émet l’adresse du compte et empêche les créations incohérentes ; l’événement permet aux indexeurs de retrouver la relation NFT-compte.
